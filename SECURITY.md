# Security

The game is a static site: no server, no accounts, no cookies and no tracking. Progress is kept
in the browser's local storage and leaves it only when the player exports it. The page runs under
a Content-Security-Policy that allows nothing from outside the site.

## Reporting a vulnerability

Please report security problems privately through GitHub: on the repository page, open
**Security → Report a vulnerability**. Do not open a public issue for them.

You can expect an answer within a week. Fixes go out with the next release, credited to you
unless you prefer otherwise.

## Supported versions

Only the version published on the live site is supported.
